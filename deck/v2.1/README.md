# Pitch deck 2.1

- `GRAVITRON-2.1-full.pptx`: the 7-slide deck with GIFs (7.3 MB). `GRAVITRON-2.1-mini.pptx`: smaller GIFs (2.4 MB, fits upload limits). `GRAVITRON-2.1.pdf`: stills.
- `notes-2.1.md`: speaker notes. `claims-2.1.md`: every claim with its source, what is not claimed, open items.
- `scripts/`: how the pictures were made. `rec.js` records GIFs with Playwright from an export of the game; `cap1.js` to `cap6.js` drive each flow; `manifest.py` collects the clips; `build_deck.js` and `lib_deck.js` build the deck with pptxgenjs. Paths inside point at a scratch folder; edit them to re-run.
